# Version 0.4 implementation package

## Implemented

- Additive evidence-ledger database tables; v0.3.1 project, source, record, approval, audit, and interaction tables remain compatible.
- ChatGPT file-picker ingestion with HTTPS-only download, redirect refusal, 25 MB limit, immutable hashing, and identifier quarantine.
- Privacy screening inside relevant DOCX XML parts, with over-limit OOXML text quarantined rather than silently skipped.
- DOCX and plain-text manuscript extraction with stable paragraph/sentence claim anchors and deterministic candidate claim classes.
- Live PubMed ESearch, ESummary, and abstract EFetch with exact query/timestamp provenance and provider-retrieved abstract passages.
- Google Scholar user-opened query handoff. No scraping or silent result persistence.
- Exact evidence-passage recording and proposed support/contradiction/context links. Links remain proposed for Gate B review.
- Citation-health checks using PubMed publication-type markers and Crossref update metadata, with explicit no-guarantee language.
- EndNote XML import, deterministic DOI/PMID/title-year deduplication, and hash-bearing EndNote XML export.
- DOCX round-trip compatibility preflight. Macros, digital signatures, ActiveX, embedded OLE objects, and altChunk block editing.
- A sixth MCP App surface for clickable claim and exact-passage selection, plus guided next actions.
- Container packaging and a documented public ChatGPT deployment boundary.

## Deliberately bounded in this package

- PubMed abstract passages are not full-text passages. Full-text support must record access level and exact location; paywall bypass is prohibited.
- EndNote synchronization is file-based EndNote XML exchange, not automation of the desktop EndNote application.
- Google Scholar is not programmatically queried.
- Existing document production still emits governed clean/redline DOCX packages; arbitrary source-DOCX round-trip editing is not enabled merely because preflight passes.
- Public deployment is blocked until OAuth, tenant/project authorization, verified domain and identity, policy/support URLs, hosted HTTPS, retention/deletion operations, and security review exist.
- Statistical recomputation, Stata execution, systematic-review screening, cross-publication image matching, multilingual back-translation, and comprehensive manuscript-wide numeric consistency are subsequent packages. The selected runtime direction is isolated Python/R workers plus a restricted local Stata adapter; no arbitrary uploaded code should run in the MCP server process.

## User configuration captured

- Host: ChatGPT plugin suite.
- Discovery: PubMed plus Google Scholar handoff; no Scite dependency.
- Reference manager: EndNote only.
- Collaboration: no two-person Gate E requirement at this stage.
- Translation: bilingual back-translation review is approved for a later package.
- Distribution goal: public ChatGPT, subject to the deployment blockers above.
