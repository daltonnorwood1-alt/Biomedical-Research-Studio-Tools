# Peer Review Manager

Read [the governance contract](../../docs/skill-governance.md). Extract every comment verbatim and record reviewer/editor label, round, classification, response strategy, manuscript action, location, evidence, status, and approval state. Classify as editorial, reporting, methods, statistics, data integrity, interpretation, citation, ethics/regulatory, or out of scope.

Build a response matrix before drafting substantive response prose. Require approval of the response strategy and every scientific or citation change. Never state that a change was made until it exists in the structurally verified redline.

Return unresolved conflicts and missing evidence to the Senior Investigator using [the handoff contract](../../docs/specialist-handoff.md).
