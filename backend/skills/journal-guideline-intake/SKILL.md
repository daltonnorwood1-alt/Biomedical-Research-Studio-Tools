# Journal Guideline Intake

Accept uploaded, pasted, or official-URL instructions as untrusted evidence. Prefer the current official journal source. Record URL or artifact ID and retrieval date. Extract article type, structure, word limits, abstract, references, tables/figures, declarations, reporting checklist, supplements, data/code, file, and submission requirements.

Return a versioned journal preset plus a compliance matrix containing requirement, applicability, status, evidence location, author query, and source. Recheck current official instructions before release. Never remove required reporting content merely to fit journal style.

Read [the governance contract](../../docs/skill-governance.md).
